# Recherche 04 — Benchmark visuel « vrai développeur / vraie agence pro »

Date : 19/11/2026. Demande : Adel trouve ses pages « fades », « pas dans l'univers de l'informatique ». Il veut un site multi-pages qui fasse vraie agence web, pas une page unique illustrée. Référence donnée : brune-mathelie.fr.

**Méthode et limites (à lire avant)**
- 15 sites lus avec WebFetch (texte, balisage, métadonnées) + articles de presse design (Abduzeedo) et fiches Awwwards. **Aucune capture d'écran** : le shell n'a pas d'accès web et l'outil ne rend pas la page. Couleurs, polices et librairies ne sont donc indiquées que si elles apparaissent dans le code lu ou dans une source citée. Sinon : « non lu ».
- Les jugements « pro / template » portent sur la structure, le texte et ce que le code révèle (Elementor, Divi, Astro, Next.js).
- Complète `02-concurrence-design.md` (concurrents locaux, prix, CTA). Ici, l'angle est **visuel et « tech »**. GooPlus (Ornex), déjà repéré en 02, est analysé ici en tant que contre-exemple.
- Écartés après lecture : Kolonell (agence à Dakar, pas à Genève), Malvah Studio (URL officielle non confirmée, articles Codrops inaccessibles), Ludovic Dind (pas d'URL de site trouvée).

## 2. Les 5 codes visuels récurrents qui font « vrai développeur / agence pro » (2026)

1. **La preuve est mesurée ou réelle, jamais décorative.** Captures de vrais sites avec lien « voir le site en ligne » (Kacz Web), type de mission par projet (Dennis, Antistatique), scores PageSpeed datés (Kaotic), journal daté (darkroom), compteurs réels dans le menu (Superhuit, basement). Les sites « template » ont l'inverse : compteurs animés à 0, photos de stock (GooPlus, Weblio).
2. **La typo porte le hero, l'image est secondaire.** Nom ou phrase-définition en très grand, une seule famille, interlettrage serré (Dennis, Corentin, darkroom, Antistatique). Pas d'illustration générique.
3. **Palette réduite : un neutre profond + un accent.** Dennis `#1C1D20` / `#455CE9`, Corentin orange / blanc / noir, Kacz Web vert `#051f17`, darkroom noir pur. Viktra a déjà ce système (encre + soleil).
4. **Les outils du métier deviennent le décor, sans jargon.** Repères de grille et références de version (Corentin), disponibilité « Available Q4, 2026 », page Statut (Weblio), Open Source (Antistatique, darkroom), llms.txt. Le terminal (Kaotic) est la version naïve de ce code.
5. **Un seul mouvement orchestré, pas des effets partout.** Préchargement de Dennis, transitions de page de Corentin. Les studios qui vont plus loin (Lusion, basement) le paient en poids. Le reste du site est statique et rapide, et c'est la rapidité qui fait « pro » sur mobile.

Code transversal côté commerçants (Kacz, Lucas, Brune, Weblio) : **transparence** = prix affichés, étapes, FAQ, « vos doutes », un seul interlocuteur, SIREN visible.

## 4. Trois directions pour Viktra

Contraintes communes : identité validée (Schibsted Grotesk seule, encre `#13212B`, craie `#F3F1EC`, aube `#F2CDBE`, matin `#CFDDE4`, léman `#1C3B4D`, calcaire `#E6E4DE`, jour `#FBFBF9`, soleil `#C4380F` en accent unique). Aucune animation liée au scroll : transitions CSS au clic et au chargement, `prefers-reduced-motion` respecté, pas de Lenis (inutile sur iPhone de toute façon, le scroll tactile reste natif), pas de blocage du zoom. Rien d'inventé : 3 réalisations (JSL Judo, textes SEO Globalpronet, appli Bonee), aucun avis. Structure multi-pages commune, inspirée de Brune Mathelié : Accueil, Services (1 page par offre : Visibilité Google, Site vitrine, Suivi, Application), Métiers (restaurants, artisans, commerces, indépendants : à ouvrir seulement quand il y a du contenu réel), Réalisations, Tarifs, Méthode, Blog, Contact.

### Direction A — « Fiche technique » (recommandée)
- **Idée** : le site se présente comme la fiche technique d'un ouvrage bien construit. Le sérieux vient des preuves mesurées, pas des effets.
- **Palette** : fond jour `#FBFBF9`, texte encre, séparateurs calcaire, soleil seulement sur le bouton principal et le point du i. Sections « preuve » sur matin `#CFDDE4`.
- **Typo** : Schibsted Grotesk 800 très grand pour le H1 (interlettrage serré comme le logo), 400/500 pour le texte, chiffres tabulaires pour les mesures.
- **Accueil** : H1 = la promesse en clair (ex. « Sites internet et fiches Google pour les commerces du Pays de Gex, de Nyon et de Genève. ») + prix d'entrée → 3 réalisations en grandes captures navigateur, chacune avec une ligne « ce que Viktra a fait » exacte (JSL Judo : création du site ; Globalpronet : réécriture des textes pour le SEO, pas le design ; Bonee : appli App Store + Google Play) → offres avec prix → méthode (vraie séquence, numérotée) → « Vos doutes » → contact avec photo d'Adel.
- **Élément signature** : sous chaque réalisation, un **bandeau de mesures daté** (score PageSpeed mobile, poids de page, temps d'affichage), relevé par Adel le jour J — et le même bandeau pour viktra.fr en pied de page. Valeurs [à mesurer], jamais estimées.
- **Références** : Kaotic (scores datés), Kacz Web (structure commerçants + prix + « voir le site en ligne »), Antistatique (H1 définition), Dennis (sobriété 2 couleurs).
- **Pourquoi** : fait « développeur » pour un non-technicien (des chiffres vérifiables), zéro coût de performance, rien à inventer.

### Direction B — « Ouvert en ce moment »
- **Idée** : rendre le slogan vivant. Le site montre qu'il « travaille » pendant que le commerce est fermé.
- **Palette** : hero aube `#F2CDBE` le jour, **léman `#1C3B4D` le soir** (bascule selon l'heure de Genève, pas selon le scroll), texte encre / craie, soleil en accent.
- **Typo** : Schibsted Grotesk, H1 « Ouvert, même quand vous êtes fermé. » en grand ; le point du i soleil réutilisé comme indicateur « en ligne ».
- **Accueil** : petit bandeau live type Superhuit : « Divonne-les-Bains · 22:14 · Votre site, lui, est ouvert. » → hero slogan + phrase d'explication → offres → réalisations → méthode → contact.
- **Élément signature** : l'**horloge locale** et le changement jour/soir, quelques lignes de JS, aucun impact sur le défilement. Option plus tard : page « Statut » publique des sites suivis (disponibilité, dernière vérification), comme Weblio, alimentée par les contrôles automatiques prévus dans le projet — seulement quand elle tourne pour de vrai.
- **Références** : Superhuit (bandeau météo Lausanne), Weblio (page Statut), darkroom (journal daté).
- **Risque** : le soir, la page sombre doit rester lisible et ne pas tomber dans le cliché « fond noir + accent vif ». Tester sur l'iPhone aux deux heures.

### Direction C — « Grille d'atelier »
- **Idée** : afficher discrètement les outils du développeur (grille, repères, versions) comme Corentin Bernadou, mais en version claire et utile.
- **Palette** : craie `#F3F1EC` + encre, lignes de grille en calcaire, soleil sur les repères actifs.
- **Typo** : Schibsted Grotesk en composition stricte, alignée à gauche sur une grille 12 colonnes visible en filigrane dans le hero.
